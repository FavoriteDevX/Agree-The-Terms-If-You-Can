# Google Account Creation Simulator (With a Twist) 🌐🍪

A highly accurate, interactive, and satirical clone of the **Google Account Creation (Privacy & Terms)** interface. Built with vanilla HTML5, modern CSS3, and high-evasion JavaScript. 

Check it out here: https://agreethetermsifyoucan.vercel.app/

## 🕹️ The Prank Mechanics

The interface looks completely harmless and identical to the authentic Google setup. However, the system is hardcoded to protect its Terms of Service at all costs:

* **The Runaway Card:** If a user moves their cursor anywhere near the **"I agree to the Google Terms of Service"** checkbox, the entire registration card dynamically calculates screen boundaries and teleports away to a random location.
* **The Evasive Button:** If the user somehow bypasses the checkbox and attempts to force-click the **"Create Account"** button without agreeing, the button breaks free from the footer layout and begins flying across the viewport.
* **The Dark-Humor Payload:** If the user manages to trick the system and successfully click "Create Account" (by catching the moving targets), they unlock a satirical Google Corporate Dashboard displaying fake profiling data.

## 🛠️ Built With

* **HTML5:** Semantic markup replicating the exact input structural workflow of Google's design.
* **CSS3 Variables & Fluid Layouts:** Standard Google material palette system (`#1a73e8` branding) along with clean transitions.
* **Vanilla JavaScript (ES6+):** Pure boundary collision tracking algorithms handling real-time runtime repositioning on both desktop mouse events and mobile viewports.
